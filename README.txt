ইমেইল দিয়ে লগইন করা Admin Panel — সেটআপ গাইড
=============================================

এখন আর GitHub টোকেন লাগবে না। আপনি admin.html এ ইমেইল ও পাসওয়ার্ড দিয়ে ঢুকবেন,
তারপর লেখা, ফোন নম্বর, লিংক, মেইন ছবি ও গ্যালারির ছবি — সব বদলাতে ও যোগ করতে পারবেন।

এই সেটআপ শুধু একবারই করতে হবে (প্রায় ১৫ মিনিট)। সবকিছু ফ্রি, কার্ড লাগে না।


ধাপ ১: Supabase অ্যাকাউন্ট ও প্রজেক্ট বানান
---------------------------------------------
1. supabase.com এ যান → "Start your project" → ইমেইল বা GitHub দিয়ে সাইন আপ করুন।
2. "New project" চাপুন।
   - Name: jessica-site (যেকোনো নাম)
   - Database password: একটা পাসওয়ার্ড দিন (কোথাও লিখে রাখুন)
   - Region: Singapore (ঢাকা থেকে সবচেয়ে কাছে)
3. "Create new project" চাপুন। ১-২ মিনিট অপেক্ষা করুন।


ধাপ ২: ডাটাবেস সেটআপ (SQL চালানো)
-----------------------------------
1. supabase-setup.sql ফাইলটা Notepad দিয়ে খুলুন।
2. ফাইলে  PUT_YOUR_EMAIL_HERE  লেখা আছে (একটাই জায়গায়)।
   ওটা মুছে আপনার নিজের ইমেইল বসান। যে ইমেইল দিয়ে admin এ লগইন করবেন সেটাই।
   উদাহরণ:  lower('jessica@gmail.com')
3. পুরো ফাইলের লেখা কপি করুন (Ctrl+A, Ctrl+C)।
4. Supabase এ বামদিকের মেনু থেকে "SQL Editor" → "New query" → পেস্ট করুন → "Run" চাপুন।
5. "Success" দেখালে হয়ে গেছে।


ধাপ ৩: আপনার লগইন অ্যাকাউন্ট বানান
-----------------------------------
1. বামে "Authentication" → "Users" → "Add user" → "Create new user"।
2. Email: ধাপ ২ এ যে ইমেইল দিয়েছেন ঠিক সেটা।
3. Password: একটা শক্ত পাসওয়ার্ড দিন (এটা দিয়েই admin এ ঢুকবেন)।
4. "Auto Confirm User" টিক দিন → "Create user"।

(ঐচ্ছিক কিন্তু ভালো) অন্য কেউ যেন অ্যাকাউন্ট খুলতে না পারে:
Authentication → Sign In / Providers (বা Settings) → "Allow new users to sign up" বন্ধ করুন।
এটা বন্ধ না করলেও অন্য কেউ সাইটে কিছু বদলাতে পারবে না, কারণ শুধু আপনার ইমেইল অনুমোদিত।


ধাপ ৪: দুটো তথ্য কপি করে config.js এ বসান
-------------------------------------------
1. Supabase এ বামে "Project Settings" (গিয়ারের চিহ্ন) → "API" (বা "API Keys")।
2. দুটো জিনিস কপি করুন:
   - Project URL      (দেখতে https://xxxx.supabase.co)
   - anon public key  (নতুন ড্যাশবোর্ডে "Publishable key" নামে থাকতে পারে, ওটাও চলবে)
3. config.js ফাইলটা Notepad দিয়ে খুলুন এবং বসান:
     SUPABASE_URL: "আপনার Project URL",
     SUPABASE_ANON_KEY: "আপনার key"
   কোটেশন ("  ") রেখে ভেতরের লেখাটুকু বদলাবেন। সেভ করুন।


ধাপ ৫: ফাইলগুলো GitHub এ আপলোড করুন
------------------------------------
আপনার GitHub repository খুলুন → "Add file" → "Upload files" → এই ফাইলগুলো টেনে ছাড়ুন:

   index.html      (পুরনোটা বদলে যাবে)
   admin.html      (পুরনোটা বদলে যাবে)
   admin.css       (পুরনোটা বদলে যাবে)
   admin.js        (পুরনোটা বদলে যাবে)
   config.js       (নতুন)
   site-data.js    (নতুন)

style.css ও script.js যেমন আছে তেমনই থাকবে, ওগুলো ছোঁবেন না।
নিচে "Commit changes" চাপুন। ১-২ মিনিট পর সাইট আপডেট হবে।

(supabase-setup.sql আর README.txt আপলোড না করলেও চলবে।)


ব্যবহার
-------
1. আপনার-সাইট/admin.html এ যান।
2. ইমেইল ও পাসওয়ার্ড দিয়ে "Log in"।
3. যা বদলাতে চান বদলান ও "Save text" / "Upload" চাপুন।
   এখন থেকে বদলালেই সাথে সাথে সাইটে দেখা যাবে (GitHub এর অপেক্ষা লাগবে না)।
   না দেখালে Ctrl+Shift+R দিয়ে রিফ্রেশ করুন।
4. কাজ শেষে "Log out"।

ছবি আপলোডের সময় বড় ছবি নিজে থেকেই ছোট (সর্বোচ্চ ১৬০০px) হয়ে যায়, তাই ফোনের সরাসরি তোলা ছবিও দিতে পারবেন, সাইট ধীর হবে না।


সমস্যা হলে
-----------
- "ইমেইল বা পাসওয়ার্ড ভুল": ধাপ ৩ এর ইমেইল/পাসওয়ার্ড আবার দেখুন।
- সেভ করতে গেলে "owner ইমেইলের সাথে মেলে না": ধাপ ২ এ বসানো ইমেইল আর লগইনের ইমেইল একই নয়।
  ঠিক ইমেইল বসিয়ে SQL আবার Run করুন (আবার চালালে কোনো ক্ষতি নেই)।
- "config.js এ বসানো হয়নি": ধাপ ৪ আবার দেখুন এবং config.js GitHub এ আপলোড হয়েছে কিনা দেখুন।
- পাসওয়ার্ড ভুলে গেলে: Supabase → Authentication → Users → আপনার ইমেইলের পাশে "..." → পাসওয়ার্ড রিসেট/বদলান।
- Supabase ফ্রি প্ল্যানে ৭ দিন কেউ প্রজেক্ট ব্যবহার না করলে সেটা ঘুমিয়ে (pause) যেতে পারে।
  তখন Supabase এ গিয়ে "Restore" চাপলেই চালু হয়ে যাবে। নিয়মিত সাইট খুললে সাধারণত সমস্যা হয় না।
