আপনার পোর্টফোলিও ওয়েবসাইট — কীভাবে সাজাবেন
================================================

ফাইলগুলো কী কী আছে
--------------------
index.html   -> ওয়েবসাইটের মূল কাঠামো (লেখা এখানে বদলাবেন)
style.css    -> ডিজাইন/রং/ফন্ট
script.js    -> গ্যালারি ছবিতে ক্লিক করলে বড় করে দেখানোর কোড
images/      -> এই ফোল্ডারে আপনার নিজের ছবি রাখবেন

১. নিজের নাম ও লেখা বদলান
--------------------------
index.html ফাইলটা যেকোনো টেক্সট এডিটরে (Notepad, VS Code) খুলুন।
"YOUR NAME" লেখা যেখানে যেখানে আছে সেগুলো নিজের নাম দিয়ে বদলে দিন।
"About" অংশের প্যারাগ্রাফটা নিজের কথায় লিখুন।
Height / Measurements / Based in — এই তিনটা তথ্য নিজের মতো বদলান, অথবা লাইনটা মুছে দিন।

২. নিজের ছবি যোগ করুন
----------------------
images ফোল্ডারে নিচের নামে ছবিগুলো রাখুন (ঠিক এই নামেই, .jpg ফরম্যাটে):
  hero.jpg        -> হোমপেজের বড় ছবি
  about.jpg       -> About সেকশনের ছবি
  gallery-1.jpg থেকে gallery-8.jpg -> গ্যালারির ৮টা ছবি

যতক্ষণ কোনো ছবি না দেবেন, ততক্ষণ ওখানে একটা "+" প্লেসহোল্ডার বক্স দেখাবে — সাইট ভাঙবে না।
৮টার কম ছবি থাকলে, index.html থেকে না চাওয়া <figure class="photo tile">...</figure>
ব্লকটা পুরো মুছে দিন।

৩. Book Now বাটনের লিংক বসান
-----------------------------
index.html এ "book" সেকশনে গিয়ে এই লাইনগুলো খুঁজুন:

  <a class="btn-book large" href="https://wa.me/8801XXXXXXXXX" ...>Book on WhatsApp</a>
  <a class="btn-link" href="https://instagram.com/yourhandle" ...>Instagram</a>
  <a class="btn-link" href="mailto:you@example.com">Email</a>

- WhatsApp লিংকে 8801XXXXXXXXX এর জায়গায় নিজের নাম্বার বসান (দেশের কোড সহ, + ছাড়া)।
- Instagram লিংকে yourhandle এর জায়গায় নিজের ইউজারনেম বসান।
- Email এ you@example.com এর জায়গায় নিজের ইমেইল বসান।
- চাইলে href="..." এর ভেতরে যেকোনো লিংক (Calendly, Facebook page, ফর্ম) বসাতে পারবেন।

৪. GitHub এ আপলোড করবেন কীভাবে
-------------------------------
এই zip ফাইলের ভেতরের সবকিছু (index.html, style.css, script.js, images ফোল্ডারসহ)
আপনার GitHub রিপোজিটরিতে "uploading an existing file" দিয়ে আপলোড করুন —
আগে যেভাবে দেখিয়েছিলাম ঠিক সেভাবেই। এরপর Vercel দিয়ে Deploy করলেই লাইভ হয়ে যাবে।

- ছবির সাইজ 2MB এর নিচে রাখলে সাইট দ্রুত লোড হবে।
